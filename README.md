# silly_cipher: A Minecraft mod that lets you use client side commands to encrypt messages in game

## Download 
Download the latest release of the mod from the release page [here](https://github.com/sillythewanderer/silly_cipher_MC/releases/latest)
Please also remember to install [Fabric API](https://modrinth.com/mod/fabric-api) and [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)

## Usage in game
Using the mod is quite simple. All current functionality is in the `/cipher` command. Currently there is only one subcommand `encrypt`, but other subcommands will be added to give the player more ways of encrypting text.
